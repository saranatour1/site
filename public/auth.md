# saranatour.dev auth.md

## Audience

Any AI agent or crawler reading this public personal website.

## Registration

None. This site has no accounts, no registration or provisioning endpoint, and no OAuth server.

## Supported methods

Anonymous read access only: `GET` and `HEAD` on public pages. See [openapi.json](/openapi.json) for the pages.

## Credentials

None are issued or accepted. Don't send any: requests are served the same with or without them.

## Usage

The usage policy is the `Content-Signal` line in [robots.txt](/robots.txt).
